# Robustness corpus. One domain per line, comments start with #.
#
# 906 domains, last extended on 2026-08-31. The mix is deliberate: a corpus of
# large sites alone would be almost uniformly configured, and this list exists to
# produce variety of failure rather than prestige. It mixes ecommerce, small and
# micro storefronts, news and media, SaaS and agencies, personal blogs, large
# consumer platforms, reference and standards sites, universities and government.
#
# The list is one flat block ordered by sha256 of the domain. It carries no
# sections, because a section boundary is a fact about the corpus that the
# ordering has no business stating. Site type lives in data/corpus_categories.csv,
# which is what scripts/run_study.py reads.
#
# Publishing platform is deliberately not a category. It is a property of a site,
# measured for every one of them and reported as a dimension that cuts across
# all of them. Making it a category produced an artifact the first time: forty
# domains read out of a Shopify directory came back 100 percent Shopify with 100
# percent llms.txt adoption, which is what that platform ships rather than what
# small businesses do.
#
# Sourcing non Shopify small businesses was attempted and did not
# work. A marketplace of 850 independent brands does not resolve, two published
# store lists return 404, and category searches return aggregators such as
# TheFork and Time Out rather than the businesses' own domains. The Shopify
# directory worked only because it publishes a sitemap. This is written down so
# nobody repeats the search expecting a different result.
#
# How these were chosen. Candidates were assembled, every entry was checked to
# resolve in DNS, and the dead ones were dropped. Where more candidates survived
# than were wanted, the selection was made by ordering on sha256(domain) and
# taking the first N. That is reproducible and it is not
# cherry picking. The candidates that did not make the cut are listed at the
# bottom of this file rather than thrown away.
#
# marshmallow-concept.com is pinned rather than sampled, at the maintainer's
# request.
