# Code of conduct

## The short version

Be decent. Assume the other person is trying to help. Disagree about the work
rather than about the person doing it.

## Scope

This applies to issues, pull requests, discussions and any other space where the
project is being worked on.

## Not tolerated

Harassment, personal attacks, discrimination on any grounds, publishing anyone's
private information, and sustained disruption of discussion.

## Specific to this project

Reports about a website are about a configuration, not about the people who run
it. This tool exists partly because a blocked `OAI-SearchBot` is usually a
misreading of a guide rather than a mistake anyone should be embarrassed by, and
because blocking model training is a legitimate decision that deserves no
lecture. Keep that tone in issues too. Naming a site to report a bug is fine.
Naming one to mock it is not.

## Enforcement

Report to the maintainer, privately if you prefer. Reports are handled in
confidence. Responses range from a request to change behaviour up to a permanent
ban, in proportion to what happened.
